# PokéCard
A simple personal project built to practice **HTML, CSS, and JavaScript** using the [PokéAPI](https://pokeapi.co/).

## Project Concept
An interactive Pokémon card that randomly generates a Pokémon and displays its:
* Type
* Height
* Weight
* Abilities
* Official artwork

There is also a **10% chance of generating a Shiny Pokémon**, with a different visual effect.

## How to Use
Clone the repository:

```bash
git clone git@github.com:Vanelli-afk/poke-card.git
```

Open `index.html` in your browser, or use **Live Server** in VS Code.

Click the card to generate another random Pokémon.
